# SyncLounge for Lazycat Platform

## 项目简介

本项目是 [SyncLounge](https://github.com/samcm/synclounge) 在 Lazycat 平台上的移植版本，让用户可以轻松地在 Lazycat 平台上部署和使用这个强大的 Plex 同步观影工具。

SyncLounge (原名 PlexTogether) 是一个用于在多个位置的多个播放器之间同步 [Plex](https://plex.tv) 内容的工具。无论用户是在同一房间还是在全球各地，SyncLounge 都能让多个观看会话保持同步，为远程观影提供完美的同步体验。

## 主要功能

- 🎬 支持跨互联网在 Plex 客户端之间同步
- 🖥️ 内置 SyncLounge 播放器
  - 直接在 SyncLounge 中播放内容
  - 专为同步优化设计
- ⚙️ 灵活的环境配置
  - 客户端轮询间隔设置
  - 同步灵活性调整
  - 多种同步方法选择
- 🌐 支持跨 Plex 媒体服务器搜索
- 👥 房间管理和主持人控制
- 📱 多平台兼容
